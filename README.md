# NEMVIA — منصة تعليمية ومجتمع أكاديمي

React + Vite + Tailwind + Supabase (Auth, Postgres/RLS, Storage, Realtime). الاستضافة: Netlify.

## ما الذي يعمل
- تسجيل دخول حقيقي: إيميل + كلمة سر، أو Google، مع استعادة كلمة المرور.
- الأدوار: طالب / معلم / أدمن (الأدمن يُعيَّن من قاعدة البيانات فقط، لا يوجد PIN).
- صفوف ومجموعات دراسة بالانضمام عبر رمز، دروس، واجبات وتسليمات وتصحيح، اختبارات تُصحَّح من السيرفر.
- مجتمع (منشورات، تعليقات، إعجابات، قصص 24 ساعة)، رسائل خاصة ومجموعات (لحظية)، رفع ملفات حقيقي.
- حصص مباشرة: رابط Jitsi تلقائي أو رابط Google Meet تلصقه أنت.
- الإبلاغ عن منشور / تعليق / رسالة، ولوحة إدارة لمراجعة البلاغات.
- ملف شخصي (صورة، نبذة، خصوصية، كلمة المرور)، حذف المحتوى وإدارة الصف (طرد عضو، أرشفة، حذف، مغادرة).
- لوحة الأدمن: بلاغات، مستخدمون (تغيير الدور وإيقاف الحساب)، إحصائيات حقيقية.
- رسائل غير مقروءة، صفحة الخصوصية والشروط (راجعها وعدّل بريد التواصل في `LegalView.tsx`).
- PWA قابل للتثبيت على الجوال، وقائمة «المزيد» على الموبايل.

## خطوات التشغيل (بالترتيب)

### 1) قاعدة البيانات (Supabase → SQL Editor)
1. مشروع جديد: شغّل بالترتيب `supabase/01_COMPLETE_SETUP.sql` ثم `02_NEMVIA_PATCH.sql` ثم `03_NEMVIA_PATCH.sql`.
2. إذا شغّلت 01 أو 02 سابقاً: شغّل الباقي فقط (02 و03 آمنان للتكرار).

### 2) إعدادات المصادقة (Authentication)
- **URL Configuration**: ضع `Site URL` = رابط موقعك على Netlify، وأضف في Redirect URLs:
  `https://اسم-موقعك.netlify.app/**` و `http://localhost:3000/**`.
- **Google**: Providers → Google → فعّله. أنشئ OAuth Client (Web) من Google Cloud Console،
  وضع في Authorized redirect URIs القيمة:
  `https://kpzidjnfntxklbkimpon.supabase.co/auth/v1/callback`
  ثم الصق Client ID و Secret في Supabase.
- **البريد**: خدمة البريد الافتراضية في Supabase محدودة جداً (رسائل قليلة في الساعة).
  قبل الإطلاق العام اربط SMTP خاص (Resend أو Brevo مثلاً) من Authentication → SMTP Settings.

### 3) حساب المالك (أدمن)
سجّل حساباً بالبريد `jamalnama19@gmail.com` وأكّد بريدك — يصبح أدمن تلقائياً (يظهر قسم «لوحة الإدارة»).
إن كان الحساب موجوداً ومؤكداً قبل تشغيل الملف 02، يُرقّى عند تشغيله.

### 4) النشر على Netlify
**الطريقة أ (موصى بها):** ارفع المجلد إلى GitHub ← Netlify → Add new site → Import from Git.
الإعدادات تُقرأ من `netlify.toml` (Build: `npm run build`، Publish: `dist`).

**الطريقة ب:** محلياً: `npm install && npm run build` ثم اسحب مجلد `dist` إلى Netlify Drop.

المتغيرات `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` اختيارية (القيم الحالية موجودة افتراضياً في الكود).
هذه مفاتيح **عامة**؛ الحماية الفعلية من RLS. لا تضع `service_role` في أي مكان.

## اختبار سريع بعد النشر
1. حساب معلم + حساب طالب (متصفحان مختلفان).
2. المعلم ينشئ صفاً ← ينسخ الرمز ← الطالب ينضم بالرمز.
3. المعلم: واجب + اختبار + درس ← الطالب يسلّم ويحلّ الاختبار ← المعلم يرصد الدرجة (يصل إشعار).
4. رسالة خاصة بين الحسابين تظهر فوراً دون إعادة تحميل.
5. بلاغ عن منشور ← يظهر عند الأدمن في «لوحة الإدارة».

## ملاحظات مهمة
- الملفات المرفوعة تُخزَّن في حاوية عامة بمسارات عشوائية: أي شخص معه الرابط المباشر يفتحه. لا تستخدمها لمستندات حساسة.
- المراسلة مفتوحة بين جميع المسجلين (بقرارك)، وزر الإبلاغ متوفر. عدّل سياسات `direct_messages` لتقييدها لاحقاً.
- الحصص المباشرة تعتمد على Jitsi / Google Meet (لا يوجد بث WebRTC داخلي). السبورة والكاميرا في صفحة «الحصص» محلية للشرح فقط.
- نقاط XP تُمنح عبر دالة بالسيرفر (حد أقصى 100 لكل عملية و300 يومياً)، وهي للتحفيز وليست للتقييم الرسمي.
- الشهادة تحفيزية داخل المنصة وغير قابلة للتحقق خارجها.
- نصوص الخصوصية والشروط قالب عام؛ يُفضّل أن تراجعها جهة قانونية قبل الإطلاق العام.
